# TicketFlow 🎫

Sistema de gestão de suporte técnico e chamados, desenvolvido com Django REST Framework.

## 📌 Funcionalidades planejadas
- Abertura de tickets por clientes
- Atribuição de técnicos
- Comentários e status por etapa
- Filtros e dashboard
- Notificações por e-mail

## 🚧 Status do projeto
> ✅ Iniciando estrutura e escopo (Mês 1, Semana 1)
> Em desenvolvimento — ✅ iniciando estrutura e escopo (Mês 1, Semana 1)

## 🧠 Objetivo
Este projeto foi criado com foco em construção de portfólio para demonstrar domínio em:
- Python e Django REST
- APIs RESTful
- Docker e versionamento
- Metodologias ágeis
- Deploy em nuvem (AWS)
